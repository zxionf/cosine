# Xel Extension

Xel 是一个用于增强 VS Code 功能的扩展，支持自定义语言服务和代码补全。

## 功能

- 🌟 支持自定义语言高亮
- 🔍 实时语法检查
- 💡 智能代码补全
- 📦 轻量级设计，性能优异



## 安装

1. 打开 VS Code。
2. 进入扩展市场，搜索 "Xel"。
3. 点击安装按钮。

## 使用方法

1. 打开 `.myl` 文件。
2. 扩展会自动启用语言服务。
3. 享受智能提示和语法检查！

## 配置选项

- `xel.enable`: 启用/禁用扩展（默认值：true）
- `xel.theme`: 设置主题风格（可选值：light, dark）
