# 风险与未决问题

> 路线与当前迭代见 `.design/阶段计划.md`；欠账见 `docs/tech_debt.md`。
> 风险是「可能挡住路线的事件」，未决问题是「还没拍板的设计选择」。

## 风险

| 风险 | 现状 | 缓解 |
|---|---|---|
| **平台覆盖** | GLFW 已改 Wayland/X11 option，但 Windows 与 X11 仍未实测 | 拿到 Windows 环境时优先跑冒烟与打包；见 R09 |
| **shader 工具链** | `slangc` 在 Windows/CI 安装不便 | 准备 `glslc` 回退或预编译 `.spv` |
| **平台差异** | Vulkan SDK、GLFW、字体与资源路径在 Windows/Linux 不同 | M5–M6 每次发版前在两端各跑一次冒烟 |
| **文本能力** | CJK 覆盖够用，字体回退、shaping、IME 缺失 | 相关项在暂停池（M4.6 T10/T11），按需重启 |
| **2.5D/3D 返工** | 若 M5–M6 把 2D 假设写死，M7 会大改 | 变换接口避免固定 `vec2`；新代码不假设「只有 x/y 平移」 |
| **视频导出** | 编码器选型、帧同步、色彩空间未定 | CO-3 开工前单独决策一次 |
| **范围蔓延** | 控件与实验容易失控 | 新控件先问「是否服务 cosine 线」；实验只在 `ui_lab` 里做 |
| **多线并行失焦** | 五条线同时推进会导致每条都半成品 | 规则：一次只主推一条线（标 ★），其余只做维护与响应 |
| **示例腐烂** | 示例随 API 演进失效却无人发现 | 示例纳入冒烟门禁（exit=0 / validation=0） |

## 未决问题

1. **Windows 最低版本与目标 GPU/驱动范围**：决定 CI 矩阵与打包目标。
2. **XEL 的类型系统边界**：动态类型是否足够，是否需要结构体/数组/模块（AN-3 期间定）。
3. **远端 CI 托管平台**：当前不维护 GitHub Actions，发布阶段再定。
4. **纹理资源的落盘形式**：CO-2 拟采用「节点存相对路径 + 加载时进纹理槽」，但
   工程文件的资源根目录、缺失资源的占位策略尚未定。
5. **`ui_lab` 实验转正的门槛**：目前约定「单测 + gallery 分区」，是否还需要
   在实测使用中验证一轮（例如进 cosine 编辑器试用）待定。

> 已解决的历史未决项（项目文件格式 = 二进制）见 `docs/project_format.md`。
