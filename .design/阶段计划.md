## 1. 任务结构

三层：**线 → 任务 → 步骤**。一条线可以挂任意多个任务，一个任务含多个 `[ ]` 步骤。

### 编号

`<线前缀>-<序号>`，序号单调递增、不复用：`UI` / `BE` / `AN` / `CO` / `EX`。
M 编号（M1–M8）只作为**历史里程碑锚点**（见第 5 节），新工作一律用任务编号。

### 状态

| 状态 | 含义 | 必填 |
|---|---|---|
| `todo` | 已排期未开工 | 目标 + 验收 |
| `doing` | 正在做（**全局最多一条**，即「主推」） | 步骤勾选进度 |
| `blocked` | 被依赖挡住 | **依赖** + 解除条件 |
| `paused` | 主动挂起 | **重启条件**（同时进第 4 节暂停池） |
| `done` | 完成 | 移到该线「已完成」表，压成一行 |

### 模板（复制到 `.design/lines/<线>.md`）

```markdown
### CO-5 任务标题（一句话）

- **状态**：`todo`
- **目标**：做完是什么样
- **验收**：可测的完成标准
- **依赖**：无 / 其他任务编号
- **步骤**：
  - [ ] 步骤一
  - [ ] 步骤二
```

### 规则

1. **一次只主推一个 `doing`**，其余线只做维护与响应。全局例外：小修可以随时插入，
   但插入的修复要在当日汇报里说明，不长期占着 `doing` 位。
2. `blocked` 与 `paused` 必须写清「什么条件下能继续」，否则视为没想清楚。
3. 步骤勾完即完成：移到「已完成」表 + 一行摘要 + 指向 `.agent/work/<id>/` 或 `docs/`。
4. 跨线接口的改动先看第 2 节；标「冻结」的先开 change 并在表里记一行。

## 3. 各线摘要

| 线 | 定位 | 质量门 |
|---|---|---|
| ui | 控件、布局、样式、输入路由、`DrawList`、字体与图集 | `ctest` 全绿；`ui_gallery` 冒烟 exit=0 / validation=0；新控件必须带单测 + gallery 分区 |
| backend | Vulkan 设备、交换链、管线、离屏与读回、shader | validation=0；ASAN 无新增泄漏（GLFW/Wayland 与 fontconfig 全局泄漏除外） |
| anim | `scene` / `property` / `timeline` / `easing` / `player` + XEL 宿主侧 | 纯逻辑单测（`test_anim_*`）+ 序列化 round-trip；错误路径不崩 |
| cosine | 编辑器产品（`cosine_editor` + `cosine`） | `ctest` 全绿；冒烟 exit=0 / validation=0；离屏导出 PNG 人工核对 |
| examples | 组合并展示现有能力、研发组合控件 | 所有示例冒烟 exit=0 / validation=0；`ui_lab` 只要求冒烟，不写断言 |

## 4. 暂停池

挂起项集中在此，避免散落成隐形负担。对应的任务在线文件里标 `paused`。

| 项 | 所属线 | 挂起原因 | 重启条件 |
|---|---|---|---|
| M4.6 T5/T6 排版（kerning、避头尾、justify） | ui | 中文排版当前可用，收益低于成本 | 出现对排版质量有硬要求的场景 |
| M4.6 T7 亚像素策略 | ui | 需要与 `pixel_snap` 组合做矩阵实验 | `ui_lab` 里有对比结论 |
| M4.6 T9 文本片段（TextSpan） | ui | 无富文本需求 | 编辑器需要行内多色文本 |
| M4.6 T10 字体回退 / HarfBuzz | ui | CJK 覆盖已够 | 需要 emoji、BiDi 或复杂脚本 |
| M4.6 T11 IME preedit | ui | 无中文输入实测场景 | 有人在真实输入法下使用 |
| M4.6 T12 SDF/MSDF | ui | 逐字号栅格化已够用 | 需要超大字号/描边/发光 |
| M4.6 T13 TreeView 行缓存（UI-4） | ui | 节点规模远未到瓶颈 | 场景节点接近上千 |
| M3.5 弹层出现/消失过渡 | ui | 需 alpha 合成与可见性生命周期改造 | 有动画资源时一起做 |
| M3.5 缓动曲线可配置 | ui | 现只插值颜色，四档够用 | UI 动画需求变复杂 |
| M3.5 逐组件单元测试 | ui | 已有 59 项测试覆盖主路径 | 某组件反复出回归 |
| R09 Windows 实测 | backend | 无 Windows 环境 | 拿到机器或远端 CI |
| R14 多窗口 / 多 Renderer | backend | 单窗口够用 | 编辑器需要多视口 |
| M6.2 `SceneView` rotation 单测 | ui | 靠截图人工验收 | 旋转逻辑再改动时补 |
