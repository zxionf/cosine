## 6. 风险与未决问题

### 风险

- **平台**：GLFW 已改为 Wayland/X11 option，但 Windows 与 X11 仍未实测。
- **shader 工具链**：slangc 在 Windows/CI 上安装不便；需要准备 glslc 回退或预编译 spv。
- **Windows**：Vulkan SDK、GLFW、字体/资源路径与 Linux 差异需要在 M5–M6 持续验证。
- **文本**：CJK 覆盖、字体回退与 shaping 仍是主要缺口（见 M4.6 的 T5/T10/T11）。
- **2.5D/3D**：如果 M5–M6 把 2D 假设写死，M7 会返工；现在就要避免固定 `vec2` 变换接口。
- **视频导出**：编码器选型、帧同步、色彩空间都需要在 M6.6 单独决策。
- **范围蔓延**：GUI 控件数量容易失控；新控件需先判断是否服务于 M6 编辑器。

### 未决问题（仍开放）

1. Windows 最低版本与目标 GPU/驱动范围。
2. XEL 的类型系统边界：动态类型是否足够，是否需要结构体/数组/模块（M5 期间定）。
3. 远端 CI 托管平台（当前不维护 GitHub Actions，发布阶段再定）。
