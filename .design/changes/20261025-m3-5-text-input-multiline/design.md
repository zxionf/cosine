## 多行文本输入

- `TextInput` 增加 `set_multiline(bool)` / `multiline()`；单行行为与现有 API 保持完全兼容。
- 多行模式：`Enter` 插入换行；`Up/Down` 在行间移动（尽量保持列位置）；`Home/End` 跳到当前行首/行尾。
- 布局：高度 = 行数 × 行高 + padding × 2，受 `set_preferred_size` 的高度上限约束；超出时产生纵向滚动。
- 渲染：逐行绘制，选区按行拆分绘制，跨行选区正确显示。
- 命中：点击按 y 判定行，再按 x 在该行内定位最近的 codepoint。
- 纵向滚动：仅当内容高度超过视口时出现；保持光标可见。

## 边界

- 不做自动换行（长行横向裁掉），换行由用户输入或程序写入 `\n`。
- 不做 Ctrl+Z/Y 撤销栈（留到后续任务）。
- 不做 IME 组合输入。
- 不做多行水平滚动条（单行仍保留原有的水平滚动）。
