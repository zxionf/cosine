## 项目文件的打开与保存（自建文件浏览）

### 背景

M6.5 第一项。此前 File 菜单三项都是占位（`pending M6.5`），项目只能存在内存里，
关掉窗口即丢。序列化与反序列化（M6.1）已经能用，缺的只是「选文件」这一层。

### 形状

分三层，各管一件事：

1. **`anim::save_project_file` / `load_project_file`**（`serialize.cpp`）
   薄封装：`serialize()` 的结果直接写盘、读盘内容直接交给 `deserialize()`。
   落盘内容与 `serialize()` **逐字节相同**，没有额外封装层 —— 这样格式文档和
   代码是同一个东西，不会出现「文档说 16 字节头，文件里多了一层容器」的偏差。
   错误统一走 `std::string* error`，给出可读原因（路径打不开 / 内容非法）。

2. **`ui::FileBrowser`**（`src/ui/file_browser.hpp`）
   自绘列表，不依赖系统对话框。约定：
   - 目录排文件前，各自按名字升序，非根目录第一项恒为 `..`；
   - 扩展名过滤**只作用于文件**，目录永远可见（否则进不去）；
   - 单击 `on_select`（外层把名字同步到输入框），双击目录进入、双击文件 `on_activate`；
   - 滚轮滚动，内容超出时右下角提示 `… +N`，避免「以为到底了」。

3. **编辑器接线**（`editor.cpp` 的 `open_project_dialog` / `save_project_as_dialog`）
   `ui::Dialog` + `ui::show_dialog`（overlay），结构是「浏览器 + 文件名输入行 + 按钮」。
   只认 `.cos`，保存时没写扩展名自动补上。`file_dialog_` 记录当前对话框，防止重复打开。

### 行为

| 菜单项 | 行为 |
|---|---|
| New | 用新 `Project` 替换内容（对象地址不变，各视图持有的引用继续有效），清空撤销栈与路径 |
| Open... | 弹浏览器，双击或选中后点 Open 加载 |
| Save | 有路径直接写；没有则转存为 |
| Save As... | 弹浏览器 + 文件名输入（默认 `untitled.cos` 或当前文件名） |

`COSINE_EDITOR_OPEN=1` 启动即弹出 Open 对话框，用于离屏截图检查布局。

### 验证

- `test_anim_serialize` 新增两组：文件 round-trip（节点数、轨道、关键帧时间、**落盘字节
  与 `serialize()` 相同**）、错误路径（不存在的目录 / 文件都要给出非空原因）。
- `test_ui_file_browser` 4 组：排序与过滤、单击选中 + 双击激活 + 进入目录 + `..` 上溯、
  路径解析（相对 / 绝对 / 空）、滚动夹取与「高度足够时不吞滚轮」。
- `ctest` **59/59**；冒烟 exit=0 / validation=0。
- `COSINE_EXPORT_PNG` + `COSINE_EDITOR_OPEN=1` 导出确认对话框布局。

### 边界

- 没有快捷键（Ctrl+O/S/N 只是菜单上的提示文字，未接全局键盘路由）。
- 不记忆上次打开的目录，每次从进程当前目录开始。
- 覆盖已有文件不二次确认。
- 资源浏览器、`Image` 真实纹理、纹理引用的序列化属于 M6.5 后续条目。
