# ui_lab — 高级 UI 实验室（EX-2）

**定位**：与 `ui_gallery` 分工明确 —— gallery 展示**已定 API**（有单测、进 SPEC），
lab 探索**未定 API** 的组合控件（无稳定测试、结论回填文档）。

这个目录的产出**不是控件本身，而是结论**：某个组合交互值不值得做成正式控件。

## 硬约束

1. **每个实验必须带「假设 / 观测 / 结论」**，结论写进下面的表；结论为空表示实验没做完。
2. **产品代码不得依赖本目录**：`src/cosine`、`src/ui`、`src/anim` 不允许 include lab 里的东西。
3. **lab 不进 ctest 断言**，只有冒烟门禁（`exit=0` 且 `validation=0`）。
4. **转正要走 ui 线的质量门**：进 `src/ui/` 时必须带单元测试 + gallery 分区，否则不算完成。

### E7 结论与缺口

- **保留**：左分类（All / Images / Fonts / Projects）+ 中列表（`FileBrowser`）+ 右预览（`Image` 占位）在 880×520 下成立。
- **保留**：单选模型（`FileBrowser::selected_index`）足够支撑预览与状态栏。
- **保留**：地址栏（Up + 单行路径 + 搜索 + Go）与窗口内底部状态栏（选中摘要 + Import 占位）。
- **已落地**：
  - `FileBrowser` 开表头（Name / Size），行命中与滚动扣除表头高度。
  - 中栏 `auto_width + flex_grow`，窗口 resize 时列表跟随，左右栏固定。
  - 搜索框接 `name_filter`（大小写不敏感，与扩展名过滤叠加）。
  - 默认选中第一个非 `..` 条目，右栏与状态栏有内容。
- **缺口 1**：`TextInput` 单行模式没有 Enter 提交回调，地址栏依赖 Go 按钮；搜索框也没有 placeholder。
- **缺口 2**：`Button` 没有 selected 样式，分类栏用 `set_pressed()` 近似选中态。
- **缺口 3**：`Image` 在 lab 中仍是占位；`ui::Image` 已支持真实纹理（UI-16），但未接 `TextureCache`。
- **缺口 4**：无目录/文件类型图标、无多选、无拖拽导入。

## 运行

```bash
cmake --build build -j4 --target ui_lab
cd build/examples && ./ui_lab
```

环境变量：

| 变量 | 作用 |
|---|---|
| `COSINE_EXIT_AFTER=<秒>` | 到点正常退出（冒烟用） |
| `COSINE_EXPORT_PNG=<路径>` | 导出 1200×800 PNG 后退出 |
| `COSINE_LAB_EXPERIMENT=<序号>` | 启动时直接打开某个实验（1 起，默认 1） |

## 冒烟

```bash
cd build/examples && COSINE_EXIT_AFTER=3 ./ui_lab 2>&1 | grep -Ei 'VUID-|validation (error|warning)' | wc -l
```

期望 `0`。

## 记一条结论的写法

```markdown
| E3 | 时间轴非线性缩放 | ... | 放大到 8 倍时关键帧拖拽精度明显提升，但吸附阈值需要随缩放调整 | 值得做，但吸附逻辑要先重写 | ✅ 已验证 |
```

结论只有三种：**提升**（交 ui 线转正）、**淘汰**（写清为什么不行）、**继续观察**（缺什么数据）。
